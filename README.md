# 🏎️ Formula 1 Power BI Dashboard

An interactive **Formula 1 Analytics Dashboard** built using **Microsoft Power BI** to analyze drivers, teams, circuits, race statistics, and championship performance.

---

## 📌 Project Overview

This dashboard provides a complete analysis of Formula 1 by combining historical and current season data into an interactive report. Users can explore driver performance, constructor statistics, circuit information, and race insights through dynamic visualizations.

---

## ✨ Features

- 🏁 Formula 1 Overview
- 👨‍🏎️ Driver Performance Analysis
- 🏆 Constructor (Team) Analysis
- 🌍 Circuit Analysis
- 📊 Interactive Filters & Slicers
- 📈 KPI Cards and Charts

---

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## 📊 Dataset

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard.
